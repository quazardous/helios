The Library lists every import in a new Imports section; a click shows that import's photos, with the other filters, nothing copied or moved. Smart albums take "import session" and "import date" rules. When an import you start ends, the Library shows it with its photos selected (setting "After an import, show it in the Library", on by default; never for automatic imports, and while you edit, its notice offers it). The import window's history offers "Show in Library", and Edit › Run Workshop… runs on the Library's selection.
