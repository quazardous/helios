A first-run setup: on the first launch, and whenever a required step is not done, the Settings app's wizard asks for the library folder (a suggested Pictures/Helios, "Choose…", checked writable with room left). "Set up Helios…" in the Helios menu opens it again. The import window asks for the folder first, then opens; left, it says why it cannot import. Health also warns when the folder is missing or read-only. Agents fill steps with `init.set`.
