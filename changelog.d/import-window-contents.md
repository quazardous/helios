The import window's Contents column shows what the sources ticked hold, read
in the background so the first thumbnails show at once: embedded previews
and Exif thumbnails, grouped by capture day (from Exif, else the file's
time), each day with a tick box and its count. Every photo is ticked; a
click toggles one, Shift+click extends, Space toggles the focused one, and
hovering shows its name, time and size. "New only" (on) greys the photos
already in your Library, found by size and a partial hash. A RAW and its
JPEG are one cell marked "RAW+JPG". Above the grid, a count line ("3,410
photos, 2,980 new, 61 GB"), a type filter (all, raw only, JPEG only) and
select all, none or the focused photo's day. The Import button says how
many photos it takes ("Import 2,980") and imports exactly those.
