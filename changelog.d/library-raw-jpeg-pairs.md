An import stacks each RAW+JPEG pair it brings in (the same name in one folder, or the same moment and camera once renamed), the raw on top. It is an import profile option, on by default, kept by every import path (window, automatic, by rule, remote), and the import's undo takes the stacks back. "Stack RAW+JPEG Pairs" in the Library does the same for photos imported before, as one undo step.
