Duplicate in the Library: Ctrl+' (Lightroom's virtual copy), Ctrl+D with the darktable keys, or the grid's context menu make a new version of the selected photos from their current edit, beside the others; "Duplicate Original" (Ctrl+Shift+D with the darktable keys) starts from no edit. The grid counts each photo's versions in a badge. Through the node's new `library.images.duplicate` and `library.versions.heads`.
