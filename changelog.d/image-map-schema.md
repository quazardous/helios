The vault gains the image map's schema (version 5): an image is in the Library by a flag, with when and by what it was set, and every file seen is a sighting (its place, size, time, hashes, capture time, camera, lens, presence). Opening an older vault takes a verified snapshot, flags every image it held as migrated and turns its locations into sightings. Every Library read (queries, cursors, stacks, locations, backup status, safe to format) leaves images out of the Library aside.
