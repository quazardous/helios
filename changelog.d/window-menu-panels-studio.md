Menus: View now holds what is shown (palette, activity, theme, zoom, full screen); Window holds where things are. Window ▸ Panels lists every panel, ticked while it shows: a closed one opens again where it was, a ticked one closes. Window ▸ Studio holds the areas, the saved studios (named arrangements of panels) and saving one, which leave View. A "+" at the end of each tab bar lists the closed panels that group can take.
