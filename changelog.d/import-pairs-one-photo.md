Importing a card or folder with RAW+JPEG pairs makes one photo per pair, as the import window shows them: the JPEG becomes the raw's camera file in the same undo step, so the Library no longer counts each pair twice and the health check has no pairs left to offer. Imported again, a pair's JPEG stays its raw's file. The import window's History lists the folder of files chosen one by one, not each file.
